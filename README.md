Electro-Master is a modern, full-stack E-commerce web application dedicated to electronic products. Built using the Java EE platform, it provides a robust and scalable solution for online retail, featuring user authentication, advanced product searching, a dynamic shopping cart, and a secure checkout system.

🚀 Key Features

👤 User Management

•	Secure Authentication: User registration and login with encrypted passwords.

•	Email Verification: Integrated account activation via unique verification codes sent to users' emails.

•	User Profiles: Dedicated "My Account" section to manage personal details and shipping addresses.

🛍️ E-Commerce Functionality

•	Dynamic Product Catalog: Categorized listing of electronics including Laptops, Smartphones, and Cameras.

•	Advanced Search: Multi-criteria filtering (Brand, Model, Category, Price Range) to help users find products efficiently.

•	Shopping Cart: Fully functional cart system allowing users to add, update, and remove items with persistent sessions.

•	Product Details: Rich product pages with multi-image support and detailed technical specifications.

💳 Checkout & Orders

•	Secure Checkout: Streamlined multi-step checkout process.

•	Order Tracking: Users can view their order history and current order status.

•	City & Delivery Data: Dynamic loading of city-based delivery options for accurate shipping.

🛠️ Technical Architecture

•	MVC Pattern: Separation of concerns between Controllers (Servlets), Models (Hibernate Entities), and Views (HTML/JS).

•	ORM Integration: Leverages Hibernate for efficient database operations and object-relational mapping.

•	Asynchronous Operations: Uses AJAX and JSON for smooth, page-refresh-free user interactions.

💻 Technology Stack

Backend

•	Core: Java EE (Servlets)

•	ORM: Hibernate 4.3.1.Final

•	Database: MySQL 8.4.0

•	JSON Processing: Google Gson 2.8.2

•	Logging: SLF4J

Frontend

•	Structure: HTML5, CSS3

•	Frameworks: Bootstrap (for responsive design)

•	Libraries: jQuery, Slick Slider, NoUiSlider, Font Awesome
•	Icons: Flaticon
